# 9. Escaped titles show backslashes in Drill-down and chart titles

**Status:** open · **Opened:** 2026-11-03 · **Source:** refuter review of SPEC §18 slice 1a

## Problem

The client renders `h1`–`h5` and `caption` Text as plain text, not markdown
(`@a2ui/web_core` `Text.js`, `NON_MARKDOWN_VARIANTS`). Two places still escape markdown into
`h4` titles:

- The executor's `_drill` builds the Drill-down title as `f"{spec.title} · {escape_markdown(label)}"`.
- `macros._fill`, used for Visual titles, escapes each placeholder value it fills.

So a label like "Acme Pty. Ltd." shows as `Acme Pty\. Ltd\.`.

## Evidence

- The slice 1a stub-app screenshot showed the same effect in a Board caption, before that was
  fixed: "ALL FIXTURE CONTRACTS\.".
- `Text.js` renders `${text}` directly for those variants.

## Options

1. Escape only where the text is rendered as markdown: body Text, `Cite`, and prose. Fill
   titles unescaped.
2. Render titles with a markdown variant. This is wrong for headings.

## Decision needed

Option 1 changes `_fill`'s contract (it escapes for markdown today), so `Cite` needs to keep
escaping while titles stop. The tests in `test_macros.py` and `test_executor.py`
(`test_drill_down_title_escapes_the_row_label`) need rewriting on purpose.
